# Задание: AssistManager — трекер привычек с огоньком + читалка по абзацам

Я новичок в программировании с агентами. Объясняй коротко, что делаешь и зачем, простыми словами. Работай по шагам, после каждого шага делай git-коммит с понятным сообщением на русском.

## Исходники

В папке `reference/` лежат два моих прототипа (одиночные HTML-файлы). Это не готовый код, а образец логики и ощущения:

- `reference/ogonek.html` — трекер мини-привычек. Стрик дней, анимированный огонь на canvas, 10 уровней огня (Уголёк 0 → Искра 1 → Огонёк 3 → Костёр 7 → Пламя 14 → Горнило 30 → Синее пламя 60 → Плазма 100 → Звёздный жар 200 → Солнце 365), заморозки стрика (+1 за каждые 7 дней, максимум 2), неделя, рекорд, резервная копия.
- `reference/reader.html` — читалка «Абзац за абзацем». Текст выдаётся по одному абзацу (или по 2–3 предложения), следующий не виден заранее — как лента TikTok. Кнопка «Дальше», «Назад», авточтение, загрузка EPUB/FB2/PDF/TXT, библиотека, запоминание места. Стиль — Disco Elysium.

Сначала внимательно прочитай оба файла целиком и перенеси всю их логику — ничего не теряй.

## Что нужно сделать

Одно приложение, в котором эти две части соединены.

### 1. Привычки
- Всё из `ogonek.html`: стрик, огонь, уровни, заморозки, неделя, рекорд.
- Таймер можно включить **для любой привычки**: длительность я задаю сам (например, 10 минут) и могу поменять в настройках привычки. Без таймера привычка просто отмечается галочкой.
- Особый вид привычки с таймером — **«Чтение»**. При нажатии она открывает читалку.

### 2. Читалка, связанная с привычкой
- Нажал на привычку «Чтение» → открывается читалка с моей текущей книгой, на месте, где я остановился.
- Сверху виден таймер привычки (обратный отсчёт до цели, например 10:00 → 0:00) и маленький огонёк.
- Таймер идёт, только пока я реально читаю: ставится на паузу, если я свернул приложение или долго (2+ минуты) не листал.
- Когда время вышло — красивое уведомление «Привычка выполнена», огонёк вспыхивает, привычка отмечается автоматически. Читать можно дальше, время продолжает копиться.
- Ведётся статистика чтения: минут за сегодня, за неделю, всего; прочитано абзацев.

### 3. Ранги и уровни
- Уровни огня по стрику — как в прототипе.
- Плюс отдельные ранги за общий опыт (XP): XP даётся за выполненные привычки и минуты чтения. Придумай 8–10 рангов с названиями в духе Disco Elysium (ироничные, литературные, на русском). Показывай прогресс до следующего ранга.

### 4. Дизайн
- Общий стиль всего приложения — Disco Elysium: тёмный фон, масляная живопись/текстура, шрифты как в `reader.html` (Old Standard TT, PT Serif, Oswald), охра, ржаво-красный акцент, нумерованные «варианты реплик» вместо обычных кнопок, где это уместно.
- Огонёк обязательно остаётся главным элементом главного экрана — но вписан в эту эстетику.
- Тексты интерфейса на русском, с лёгкой иронией, как внутренний голос из игры (можно реплики «навыков» вроде «ВОЛЯ: Ещё один абзац. Ты можешь.»).
- Удобно на телефоне в первую очередь.

### 5. Звуки (после дизайна)
- В духе Disco Elysium: треск огня, отметка привычки, вспышка при выполнении, повышение уровня и ранга, мягкий звук листания абзаца, сигнал конца таймера.
- Только свои звуки (синтез Web Audio или CC0), ничего из самой игры.
- Выключение звука в настройках.

### 6. Напоминания (после звуков)
- Как в Duolingo: уведомления в выбранное мной время, если привычки не сделаны, с ироничной репликой «навыка» («ВОЛЯ: Огонь гаснет. Ты это допустишь?»).
- Вечером — предупреждение, что стрик сгорит.
- Должно работать, когда приложение закрыто.

### 7. Виджет на главный экран Android (последний шаг)
- Огонёк, стрик, сколько привычек осталось сегодня. Нажатие открывает приложение.
- Нативный код на Kotlin.

## Технически
- **Итог — установочный APK для Android.** Это главное требование.
- Я не хочу ничего устанавливать и настраивать сам, кроме Git. Поэтому:
  - Интерфейс и логика — HTML + CSS + JavaScript (без тяжёлых фреймворков), разбитые на понятные файлы.
  - Оборачивай в Android-приложение через **Capacitor**.
  - **APK собирается автоматически в GitHub Actions** при каждом пуше в main: настрой workflow, который ставит JDK и Android SDK, собирает debug-APK (подписанный, устанавливаемый) и публикует его в **GitHub Releases** с понятным названием (например `AssistManager.apk`), чтобы я скачивал его по одной ссылке прямо с телефона.
  - Не требуй от меня Android Studio, Node.js или Java на компьютере. Если что-то из этого нужно тебе для проверки — ставь сам или проверяй через GitHub Actions.
- Работает полностью офлайн. Данные хранятся на устройстве, плюс экспорт/импорт резервной копии в файл.
- Загрузка книг из памяти телефона (EPUB/FB2/PDF/TXT) должна работать внутри APK.
- Таймер чтения корректно встаёт на паузу при сворачивании приложения.
- Иконка приложения — огонёк в стиле Disco Elysium, название на телефоне — «AssistManager» (или предложи лучше).
- Создай `README.md` на русском: что это, как устроены файлы, где скачать APK.
- Всё, что касается git и GitHub (init, подключение к репозиторию, коммиты, пуши), делай сам. Мне только скажи, когда нужно войти в GitHub в браузере.

3. После каждого шага пушь в GitHub и давай ссылку на свежий APK, чтобы я проверил на телефоне.
